# KeyPrompt Advanced

KeyPrompt Advanced is the local-LLM-capable version of the KeyPrompt product family.

It assumes the KeyPrompt Lyte baseline is complete and adds local compute hardware, model storage, cooling, and expanded power design.

## Dependency

KeyPrompt Advanced depends on:

- KeyPrompt Lyte architecture.
- KeyPrompt Lyte keyboard-only HID output.
- KeyPrompt Lyte safety model.
- KeyPrompt Lyte touchscreen approval workflow.
- KeyPrompt Lyte battery and enclosure baseline, modified as required for compute power.

## Scope

Advanced adds:

- Local LLM compute module.
- Local model runtime.
- Model storage.
- Thermal management.
- Expanded enclosure.
- Expanded power distribution.
- Optional cloud/API fallback.
