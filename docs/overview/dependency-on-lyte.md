# Dependency on KeyPrompt Lyte

KeyPrompt Advanced begins after KeyPrompt Lyte baseline completion.

Inherited from Lyte:

- Touchscreen prompt/review/approval workflow.
- Keyboard-only USB HID output.
- RP2040 output bridge.
- Gated OFF/KILL — REVIEW — INJECT mode switch.
- External hardware-state LEDs.
- Safety state machine.
- Patent and documentation conventions.

Advanced adds local compute but does not replace the Lyte safety boundary.
