# Requirements — KeyPrompt Advanced

## Added Functional Requirements

- AFR-001: Run or access a local LLM service onboard.
- AFR-002: Store local model files.
- AFR-003: Manage model selection and runtime status.
- AFR-004: Maintain Lyte-compatible touchscreen approval.
- AFR-005: Maintain Lyte-compatible RP2040 keyboard-only output.

## Added Power Requirements

- APR-001: Support compute-module power budget.
- APR-002: Monitor compute thermal state.
- APR-003: Prevent undervoltage conditions during inference.

## Added Thermal Requirements

- ATR-001: Provide active or passive cooling as required.
- ATR-002: Report thermal warning conditions.
