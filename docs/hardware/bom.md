# BOM — KeyPrompt Advanced

This BOM assumes KeyPrompt Lyte is already complete.

## Added Hardware

| Qty | Item | Economy | Mid-Tier | High-End |
|---:|---|---|---|---|
| 1 | Local compute module | Raspberry Pi 5 class | Orange Pi 5 Plus / Jetson Orin Nano class | x86 mini PC / high-RAM module |
| 1 | Model storage | 256 GB NVMe/eMMC | 512 GB NVMe | 1 TB+ NVMe |
| 1 | Cooling | Heatsink | Heatsink + fan | Ducted active cooling |
| 1 | Power expansion | Separate PSU during bench testing | Internal distribution board | Custom protected power PCB |
| 1 | Enclosure expansion | Larger printed case | Vented compute compartment | Serviceable enclosure with thermal channels |

## Retained from Lyte

- ESP32-S3-Touch-LCD-7B.
- RP2040 keyboard HID bridge.
- Gated mode switch.
- External hardware-state LEDs.
- Touchscreen approval workflow.
